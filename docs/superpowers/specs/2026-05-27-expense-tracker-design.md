# 记账功能设计

## 概述

为情侣小程序"奶龙的家"添加极简记账功能，支持记录共同花销和AA制，预设分类，云端存储双方共享。

## 功能范围

- 记录一笔支出：金额 + 分类 + 谁付的 + 备注
- 5个预设分类：🍜吃饭 🚗交通 🎁礼物 🎮娱乐 📦其他
- 本月统计：总支出、我付、TA付
- 记录列表：按时间倒序展示
- 云数据库存储，双方都能查看

## 数据模型

### expenses 集合

```javascript
{
  _id: "auto",
  _openid: "创建者openid",
  coupleId: "情侣ID",
  amount: 158,          // 金额（数字，单位：元）
  category: "吃饭",     // 分类：吃饭/交通/礼物/娱乐/其他
  paidBy: "openid",     // 谁付的（openid）
  note: "火锅",         // 备注（可选）
  date: "2026-05-27",   // 日期
  createdAt: "2026-05-27T12:30:00Z"  // 创建时间
}
```

### 索引

- `coupleId + date` — 按日期查询
- `coupleId + createdAt` — 按时间排序列表

## 云函数

### addExpense

- 入参：coupleId, amount, category, paidBy, note, date
- 写入 expenses 集合
- 返回 success + entryId

### getExpenses

- 入参：coupleId, year, month
- 查询当月所有记录，按 createdAt 倒序
- 返回 entries 数组 + stats（total, myTotal, partnerTotal）

## UI 组件

- 顶部统计卡片：渐变背景，显示本月总支出、我付、TA付
- 分类选择器：横向排列的胶囊按钮，点击选中高亮
- 谁付的：二选一按钮组
- 金额输入：数字键盘输入
- 备注输入：文本框，可选
- 保存按钮：橙色渐变
- 记录列表：卡片式，显示分类图标、备注、时间、金额

## 入口位置

记账页面作为子页面，从首页或乐园页面的快捷入口进入，不占用 TabBar。

## 样式规范

- 沿用现有设计语言：橙色渐变、毛玻璃卡片、圆角
- 分类选中态：橙色边框 + 浅橙背景
- 金额数字：加粗，红色/橙色
- 记录卡片：白色背景，左侧分类图标，右侧金额
