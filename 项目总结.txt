项目名称：奶龙的家
技术栈：uni-app (Vue 3 + Pinia) + 微信云开发（云函数 + 云数据库 + 云存储）

1. 核心痛点
这是一个情侣私密空间小程序，解决了传统情侣 App 的几大痛点：
- 分开记账 — 大部分情侣 App 的硬币共享，一人花完另一人没得用。
  改为个人独立金币，各自赚各自花。
- 奖励自定制 — 扭蛋机预定义奖励太死板。
  改为用户自定义奖池，权重、类型、内容完全自由。
- 商品互买 — 小卖部支持一方上架、一方购买，券包购买者独享使用权限，
  另一方只能看到已使用状态。
- 关系数据可视化 — 任务打卡、植物成长、梦想进度一目了然。
- 隐私轻量 — 不依赖微信头像/性别接口（微信已禁用），改用手动上传和本地存储。
2. 核心逻辑流
技术架构：传统 C/S 架构，无多 Agent 协作，无长链推理
用户操作 (uni-app)
  → 微信小程序 API / 云函数调用
  → 云函数 (Node.js, wx-server-sdk)
  → 云数据库 (MongoDB-like) / 云存储
  → 返回结果 → Pinia 状态管理 → 前端渲染
3. 核心业务模块
┌─ 首页（植物园）
│   植物状态展示（幼苗/成长/开花/茂盛四阶段）
│   每天每人一次手动浇水 + 任务/签到自动浇水
│   订阅消息横幅（点此开启微信通知）
│   今日打卡快捷入口
│   最近动态（最近5条）
│
├─ 任务
│   发布任务（选择难度：简单1币/中等3币/挑战5币）
│   支持一次性/每日/每周三种类型
│   对方提交 → 发布者审核通过/拒绝 → 通过后自动发币
│
├─ 乐园
│   ├─ 扭蛋机
│   │   自定义奖池（可添加/编辑/删除奖励）
│   │   每个奖励可设类型、图标、权重、描述
│   │   消耗2币抽奖（按权重随机选中）
│   │   奖励类型：小奖励、互动币、肥料、成就碎片、限定卡
│   │
│   └─ 小卖部
│       商家上架商品（服务券/实物券/特权券）
│       商品可设价格、库存
│       购买生成券包 → 仅购买者可使用
│
├─ 梦想
│   添加梦想（选择类型+标题）
│   标记完成/未完成（可互相点赞）
│   进行中/已完成筛选
│   编辑/删除梦想
│
└─ 我们（个人中心）
     双方头像展示（cloud:// 云存储，支持手动上传）
     情侣名、在一起天数
     性别设置（按钮选择）
     关系数据面板（累计任务/植物状态/梦想完成）
     券包管理（仅本人可操作自己的券）
     设置弹窗（改情侣名、邀请码、植物品种）
4. 经济系统
金币 — 个人独立账户，非情侣共享
  赚：完成任务（1/3/5币）、签到
  花：扭蛋（2币/次）、小卖部购物
券包 — 购买者独享使用权限
  购买后生成券 → 仅购买者可使用 → 使用后状态同步
5. 数据安全
所有数据库操作通过云函数执行（服务端特权模式）
前端不直接操作数据库，解决了微信小程序数据库权限配置复杂的问题
订阅消息需要用户主动授权（wx.requestSubscribeMessage）
